# Contributing

Se quiser contribuir, abra uma issue primeiro descrevendo o que pretende fazer. Evita trabalho duplicado.

## Padrões

- C++17
- Código em inglês, comentários podem ser em português ou inglês
- Headers com `#pragma once`
- Namespaces: `nocturne::core`, `nocturne::unity`, etc.
- Sem `using namespace` em headers
- Nomes claros, sem abreviações obscuras

## Pull Requests

1. Fork
2. Branch: `git checkout -b feature/nome`
3. Commit com mensagem descritiva
4. Push e abra PR

## Reportando bugs

Inclua:
- Versão do Windows
- Jogo e versão do Unity alvo
- Offsets e patterns usados
- Passos para reproduzir
- Logs ou screenshots se aplicável
